Deep Dream

A surreal 2D maze exploration game developed with Unity 6.

Overview

Deep Dream is a 2D maze game inspired by LSD: Dream Emulator and Paprika, exploring the idea that ordinary rules no longer apply within dreams.

Players navigate three interconnected dream worlds, searching for a way to wake up. Doors and windows lead to randomly selected dream locations, while jumping into a hole is the only way to escape.

Game Features

* Three Dream Worlds: Underground, Ocean, and Festival, each with a distinct visual atmosphere.
* Randomized Transitions: Doors and windows transport players to different dream locations.
* Unconventional Escape Mechanic: Players must discover that the true exit is a hole rather than a door.
* Original Soundtracks: All background music was composed specifically for the game, with different musical atmospheres for each world.
* Ambiguous Ending: The game leaves players questioning whether they have truly awakened.

Development

* Game Engine: Unity 6
* Platform: macOS
* Genre: 2D Maze / Exploration
* My Contributions: Game programming, level design, gameplay mechanics, soundtracks, and visual direction.

Some background images and objects were created with generative AI and subsequently edited and adapted for the game.
